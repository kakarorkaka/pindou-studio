AI 风格化

检查 AI 服务…

用混元生图把照片变成好拼的风格；两个预设都会自动输出纯白背景，再用现有算法转成四档图纸。

生成约 20 秒，每次会消耗一次混元额度；白底已包含在风格里，使用后会自动去背景。图片只发送到你在本机配置的 AI 代理，Key 不会进入网页。

正在生成…

1. 启动本地代理

# 在项目根目录
node tools/hunyuan-proxy.mjs

2. 提供混元 Key（任选一个，Key 不要发到网页）

HUNYUAN_API_KEY=sk-... node tools/hunyuan-proxy.mjs

代理也会自动读取 KOK 的 image_gen_api_key。详见 tools/README.md。

3. 服务地址

线上页面也可以连本机代理；如果部署了 Cloudflare Worker，把地址填这里。

作品

内测精选作品 · 点「拼同款」可直接载入工作台编辑与导出。

发布到作品墙

内测采用审核制：投稿需 GitHub 账号，通过后出现在作品墙（1–3 天）。没有账号可先复制文案发小红书。

提交会打开 GitHub 投稿页（内测通道），分享链接会自动填入。

使用指南

  1. 选择图纸来源图片（照片 / 插画）、文字（名字 / 祝福语）或模板。
  2. 选择规格速成 / 标准 / 精细决定豆数；品牌选你手头的豆子。
  3. 微调并导出在工作台点格改色、排除色号，再导出 PNG / 打印 / 清单。
色号和我买的豆子不一致？

不同品牌色号体系不通用，同一颜色在 MARD 是 A01、在盼盼可能是另一个编号。请先确认品牌；色号数据参考公开色卡整理，购买前建议与实物色卡核对。

打印出来尺寸不对？

打印时选择「实际大小 / 100% 缩放」，不要用「适合页面」。图纸标题栏会标注总格数，可据此核对。

图片会被上传吗？

不会。图片、生成与导出全部在浏览器本地完成，没有账号、没有上传接口。

作品存在哪里？

仅保存在当前浏览器的本地数据库（IndexedDB），清除浏览器数据会丢失；不会同步到云端。

怎么分享给朋友？

在工作台点「导出图纸」→「分享图纸」：可以下载带二维码的分享卡，或复制一个能还原图纸的链接。

能装到手机桌面吗？

可以。Chrome：菜单 →「添加到主屏幕」；Safari：分享 →「添加到主屏幕」。安装后可离线使用已加载的页面。

图纸库是什么？

官方精选的 30 件图纸，点「拼同款」可以直接载入工作台编辑、导出。内测阶段暂不开放用户上传。

快捷键：B 画笔 · E 橡皮 · I 取色 · H 移动 · F 适应窗口 · G 网格 · ⌘Z 撤销 · ⌘E 导出
