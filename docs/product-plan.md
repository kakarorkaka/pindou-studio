# 拼豆工作室 · 产品进阶方案（商业化版）

> 本文件是 v1.1 的产品决策记录：为什么做、做什么、怎么衡量。

## 1. 定位

**给「想动手做一件东西的人」的拼豆图纸工作台。**

- 不是 AI 出图玩具，而是**可执行的生产资料**：真实品牌色号、颗数、坐标、打印版、购物清单。
- 一句话价值：*把一张图，变成能照着拼、能直接买豆、能打印出来的图纸。*
- 差异点（竞品缺的）：**本地即时处理**（不排队/不扣点/不上传）、**完整交付**（不是截图）、**可编辑可回退**、**成本透明**（豆数/尺寸/耗时一直可见）。

## 2. 用户与场景

| 用户 | 场景 | 诉求 |
|------|------|------|
| 手作新手 | 小红书看到图想照着拼 | 3 步出图、别太贵、别太难 |
| 进阶玩家 | 自己找图、改图、送人 | 可编辑、可打印、色号准确 |
| 手作店主 | 接单定制、批量 | 清单、复用、批量 |
| 亲子/社团 | 一起做 | 简单、有趣、不用注册 |

## 3. 增长闭环（为什么能上榜）

```
看到分享卡/链接 → 打开即用（免登录）→ 3 步生成 → 导出图纸
        ↑                                        ↓
        └────── 分享图纸链接 / 分享卡 / 模板 ────────┘
```

关键杠杆，按优先级：

1. **零门槛进入**：不用注册、打开即用、示例图一键体验。
2. **可传播的产物**：分享卡（带作品与站点信息）+ **可还原的分享链接**（别人打开就是同一张图纸）。
3. **留存抓手**：本地作品库、自动保存、最近作品。
4. **内容钩子**：模板库（爱心/星星/小花…）与「文字转图纸」（名字、祝福语）——小红书最容易被搜索的需求。
5. **可分发性**：PWA 可安装、离线可用（App 化的最低成本路径）。

## 4. 本版本（v1.1）交付范围

| 模块 | 内容 | 目的 |
|------|------|------|
| 三模式 | 图片 / 文字 / 模板 | 覆盖「找图难」与「定制字」两大高频场景 |
| 风格化 | 卡通 / 像素 / 剪影 | 让照片转图纸更「像作品」，提升成图率 |
| 分享 | 分享链接（图案编码进 URL）+ 分享卡（1080×1350） | 病毒传播 |
| 作品库 | IndexedDB 自动保存、最近作品、恢复编辑 | 留存与复用 |
| PWA | manifest、Service Worker、图标、离线 | 安装与复访 |
| 商业化框架 | 帮助中心、Pro 价值页、「内测免费」说明 | 为付费做预期管理，不设假付费墙 |

## 5. 商业原则

- **免费版必须能完整完成一次交付**（生成 → 编辑 → 导出）。不靠阉割核心功能逼付费。
- **Pro 卖效率与表达**：批量处理、无水印高清分享卡、更多风格与模板、优先体验 AI 能力。
- **内测期全部免费**，标明「未来 Pro 功能」但不阻断当前使用；不伪造倒计时、不诱导分享。
- 数据留在本地：作品只存在浏览器 IndexedDB，可一键清除。

## 6. 指标

| 层级 | 指标 | 目标 |
|------|------|------|
| 北极星 | 完成导出/分享的会话占比 | ≥ 55% |
| 获取 | 分享卡/链接带来的打开 | 观察 |
| 激活 | 首次出图 ≤ 60s；示例图使用率 | ≥ 30% |
| 留存 | 7 日内再次打开 / 打开最近作品 | ≥ 25% |
| 传播 | 每 100 次导出产生的分享 | ≥ 8 |
| 质量 | 生成失败率；导出失败率 | < 0.5% |

## 7. 风险与对策

| 风险 | 对策 |
|------|------|
| 功能膨胀、首屏变重 | 三模式并列但面板轻量；高级参数仍折叠 |
| 分享链接过长 | deflate 压缩 + RLE；超长时提示改用分享卡 |
| 作品占空间 | 只存 800px 源图 + 缩略图，最多 30 个，可删除 |
| 商业化伤害体验 | 内测全免费；Pro 只卖效率，不卖「能不能用」 |
| 品牌色号争议 | 明确「以实物色卡为准」，提供近似色逻辑 |

## 8. 路线图

- **v1.1（本次）**：三模式、风格化、分享、作品库、PWA、帮助/Pro。
- **v1.2**：批量处理、PDF 分页、自定义色板、模板投稿。
- **v2.0**：AI 风格化（风格库 + 强度控制 + 主体分割），可选云端，失败自动回退。
