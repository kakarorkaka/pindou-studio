# 作品墙与投稿（内测）

作品墙是「精选制」：所有作品在展示前都经过审核。内测阶段不开放即时上传，避免低质量内容、侵权与审核风险。

## 用户怎么投稿

1. 在工作台完成一张图纸。
2. 「导出图纸 → 发布到作品墙」。
3. 填写作品名、标签、分类，勾选权利声明。
4. 点「提交审核」，会自动打开 [pindou-community](https://github.com/kakarorkaka/pindou-community/issues/new) 的投稿 Issue，内容已填好。
5. 在 Issue 中提交，等待审核（1–3 天）。

没有 GitHub 账号的用户，可先点「复制小红书文案 / 下载分享卡」把作品发到外部平台；站内投稿通道会在开放账号体系后提供。

## 审核标准

- 图纸完整、可拼，色号 / 品牌 / 颗数准确
- 不侵犯著作权；二创必须注明来源，且仅限免费分享
- 同一作品不重复提交
- 实拍成品加分，但不强制

## 审核流程（维护者）

1. 打开 Issue，确认：
   - 分享链接可用（`#p=` 或完整 URL）
   - 权利声明已勾选
   - 非明显侵权 / 违规内容
2. 打开链接，检查图纸质量与规格。
3. 通过：在 Issue 打 `approved` 标签并回复「已通过」。
4. 下架 / 拒绝：说明原因，打 `needs-info` 或直接关闭。

## 把通过的作品加入作品墙

作品墙数据在 `js/community-works.js`，缩略图在 `assets/works/`。

一条作品的数据结构：

```js
{
  id: "cat-40",                 // 唯一 id，建议「模板-尺寸」或作者-编号
  title: "猫咪 · 标准图纸",
  author: "拼豆工作室",
  category: "动物",              // 动物 / 植物 / 节日 / 文字 / 新手 / 其他
  tags: ["动物", "标准"],
  cols: 40, rows: 49,
  total: 1337, colors: 3, brand: "MARD",
  thumb: "assets/works/cat-40.webp",
  preview: [{ code: "H06", hex: "#2F2B2F", count: 1200 }],
  code: "z...",                 // 分享链接 payload（#p= 后面的部分）
  order: 9,
  featured: 1                   // 1 = 首页精选，0 = 普通
}
```

生成方式：维护者用工作台打开投稿链接 → 导出分享链接得到 `code`；截图 / 导出缩略图保存为 `assets/works/<id>.webp`；补齐元信息后提交部署。

## 权利与下架

- 投稿即确认拥有权利或已获授权。
- 收到侵权投诉：先下架，再核实；重复侵权封禁投稿。
- 付费图纸市场（后续）只接受原创/授权作品，二创不进入付费。

## 开放上传的前置条件

真正开放「注册 + 即时上传」需要：

- 后端（账号、作品存储、点赞收藏、举报）
- 内容审核（机器 + 人工）与举报处置
- 中国大陆运营需 ICP / 公安备案、实名、未成年人保护等
- 审核与客服人力

在这些就绪前，保持「审核制投稿 + 精选展示」是更稳的产品选择。
